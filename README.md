## Explain Details of Project Directory Structure

- **fundamentals:** This directory houses the core building blocks of programming, such as:
  - **design-principles:** Articles on SOLID principles, DRY (Don't Repeat Yourself), KISS (Keep It Simple, Stupid), and more.
  - **data-structures-and-algorithms:** Notes on arrays, linked lists, trees, graphs, sorting algorithms, etc.
- **frontend/backend/devops/system-design:** These directories store knowledge specific to different development areas, categorized by technologies and frameworks.
- **projects:** A dedicated space for our project-specific notes and learnings.
